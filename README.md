# Daniel Scott Thriller Website Sample

Static author-site concept for Daniel Scott, built as a dark thriller landing page around the `Dark Pursuits` series.

## Stack

- Plain HTML/CSS/JS
- No build step required
- Ready for GitHub Pages, Cloudflare Pages, or any static host

## Files

- `index.html` — page structure, SEO metadata, JSON-LD author schema
- `styles.css` — dark supernatural thriller visual system
- `script.js` — sticky header state, copyright year, demo form behavior

## Local preview

```bash
python3 -m http.server 4173
```

Then open `http://127.0.0.1:4173`.

## Launch notes

Before making this a live author site:

1. Replace placeholder/sample positioning copy with final Daniel Scott copy.
2. Wire the reader-list form to the actual email provider.
3. Replace CSS-generated book-cover cards with final cover art if desired.
4. Confirm Amazon links and affiliate/tracking parameters.
5. Connect `danielscottbooks.com` through Cloudflare Pages.
